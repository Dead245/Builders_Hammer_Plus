# Builder's Hammer+

Mod for Hytale.

Adds more functionality to the vanilla Builder's Hammers.  Also adds 1 new hammer, the the Thorium Builder's Hammer.

<img width="288" height="94" alt="3Hammers3Modes" src="https://github.com/user-attachments/assets/17a22e8b-dcbb-42fc-82e3-aff77805409a" />

---
All Builder's Hammers will now have multiple modes, each having multiple functions and cycleable settings.
1. (Default) - Cycle mode
2. State mode
3. Rotate mode
